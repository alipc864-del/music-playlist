# 🎵 Music Playlist

A modern and responsive music playlist built with HTML, CSS and JavaScript.

## ✨ Features

- 🎵 Multiple songs
- ▶️ Play and pause controls
- ⏮️ Previous and next song
- 🔊 Volume control
- 🎚️ Music progress bar
- 🔍 Search songs
- ❤️ Favorite songs
- 🗑️ Remove songs from playlist
- 🖼️ Custom cover image for each song
- 🎨 Dynamic theme based on each song
- 🌈 Smooth theme color transitions
- 📱 Responsive design
- ✨ Modern dark UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- HTML Audio API

## 🚀 About

This project was created to practice JavaScript, DOM manipulation, audio controls, search functionality and dynamic UI themes.

Each song has its own cover image and theme color. When the song changes, the interface smoothly transitions to the new theme.
